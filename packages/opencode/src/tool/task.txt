启动一个新的Agent以自主处理复杂的多步骤任务。

使用 Task 工具时，你必须指定 subagent_type 参数来选择要使用的Agent类型。

何时使用 Task 工具：
- 当你被指示执行自定义的斜杠命令时。使用 Task 工具，并将斜杠命令调用作为整个提示内容。斜杠命令可以接受参数。例如：Task(description="检查文件", prompt="/check-file path/to/file.py")

何时**不要**使用 Task 工具：
- 如果你想读取特定的文件路径，请改用 Read 或 Glob 工具，以更快地找到匹配项
- 如果你正在搜索特定的类定义，如 "class Foo"，请改用 Glob 工具，以更快地找到匹配项
- 如果你正在搜索特定文件或 2-3 个文件集合中的代码，请改用 Read 工具，以更快地找到匹配项
- 与上述Agent描述无关的其他任务

使用说明：
1. 尽可能并发启动多个Agent，以最大化性能；为此，请在一个消息中使用多个工具调用
2. 当Agent完成后，它将返回一个单一的消息给你。Agent返回的结果对用户不可见。要向用户展示结果，你应该向用户发送一条文本消息，简要总结结果。输出中包含一个 task_id，你可以稍后重用以继续同一个子Agent会话。
3. 每次Agent调用都从一个全新的上下文开始，除非你提供 task_id 来恢复同一个子Agent会话（该会话会继续其先前的消息和工具输出）。当从头开始时，你的提示应包含高度详细的任务描述，供Agent自主执行，并且你应该明确指定Agent在其最终且唯一的消息中应返回给你的信息。
4. 通常应该信任Agent的输出
5. 清楚地告诉Agent你是期望它编写代码，还是仅仅进行研究（搜索、文件读取、网页抓取等），因为它不知道用户的意图。如果可能，告诉它如何验证其工作（例如，相关的测试命令）。
6. 如果Agent描述中提到应该主动使用它，那么你应该尽最大努力使用它，而不必等待用户先请求。请运用你的判断。
