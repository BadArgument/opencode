启动一个新的Agent以自主处理复杂的多步骤任务。

使用 Task 工具时，你必须指定 subagent_type 参数来选择要使用的Agent类型。

何时使用 Task 工具：
- 当你被指示执行自定义的斜杠命令时。使用 Task 工具，并将斜杠命令调用作为整个提示内容。斜杠命令可以接受参数。例如：Task(description="检查文件", prompt="/check-file path/to/file.py")

何时**不要**使用 Task 工具：
- 如果你想读取特定的文件路径，请改用 Read 或 Glob 工具，以更快地找到匹配项
- 如果你正在搜索特定的类定义，如 "class Foo"，请改用 Glob 工具，以更快地找到匹配项
- 如果你正在搜索特定文件或 2-3 个文件集合中的代码，请改用 Read 工具，以更快地找到匹配项
- 与上述Agent描述无关的其他任务

使用说明：
1. 尽可能并发启动多个Agent以提升性能；实现方式是：在同一条消息中包含多个工具调用（tool uses）。
2. Agent执行完成后，会向你返回一条消息。该结果对用户不可见。如需向用户展示结果，你需要再发送一条文本消息，并对结果进行简要总结。输出中会包含一个 task_id，你可以在后续复用它以继续同一子Agent会话。
3. 如果已启用 OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS，设置 background=true 将以异步方式启动子Agent。可使用 task_status(task_id=..., wait=false) 进行轮询，或设置 wait=true 以阻塞等待完成。
4. 除非提供 task_id 以恢复已有会话，否则每次调用Agent都会从一个全新的上下文开始。全新启动时，你的提示词应包含高度详细、可供Agent自主执行的任务说明，并明确指出Agent应在其最终且唯一的返回消息中向你提供哪些信息。
5. 一般情况下，应信任Agent的输出结果。
6. 明确告知Agent你是期望它编写代码，还是仅进行研究（搜索、读取文件、抓取网页等），因为它无法自行推断用户意图。如有可能，说明其应如何验证工作成果（例如相关的测试命令）。
7. 如果Agent描述中提到应“主动使用”，则应尽可能在不等待用户明确要求的情况下使用它。请结合判断合理使用。
