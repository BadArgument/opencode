- 从指定的 URL 获取内容
- 输入一个 URL 和可选的格式
- 获取 URL 内容，转换为请求的格式（默认为 markdown）
- 返回指定格式的内容
- 当你需要检索和分析网页内容时，请使用此工具

使用说明：
  - **重要**：如果存在另一个提供更好网页获取能力、更针对任务或限制更少的工具，请优先使用该工具，而不是此工具。
  - URL 必须是一个完整的有效 URL
  - HTTP URL 将自动升级为 HTTPS
  - 格式选项："markdown"（默认）、"text" 或 "html"
  - 此工具是只读的，不会修改任何文件
  - 如果内容非常大，结果可能会被总结
